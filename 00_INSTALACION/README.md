# 00 — Instalación y compilación

Objetivo: verificar que Windows 11, Visual Studio Community 2026 e Intel oneAPI estén correctamente configurados.

1. Instalar Visual Studio Community 2026 con herramientas C++.
2. Instalar Intel oneAPI Base Toolkit.
3. Instalar Intel oneAPI HPC Toolkit.
4. Verificar `C:\Program Files (x86)\Intel\oneAPI\setvars.bat`.
5. Ejecutar `compilar.ps1`.
6. Ejecutar `ejecutar.ps1`.

Resultado esperado: el programa imprime `TECPROG WORLD - FORTRAN 2026`.
