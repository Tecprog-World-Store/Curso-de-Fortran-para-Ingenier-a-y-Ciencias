# 09 — Aplicación de ingeniería: flujo en tubería

El programa lee caudal, diámetro, longitud, rugosidad y viscosidad cinemática desde `entrada.dat`, calcula velocidad, número de Reynolds, factor de fricción de Swamee-Jain y pérdida de carga de Darcy-Weisbach.

Este módulo integra arrays/variables, control, I/O, funciones, subrutinas y módulos.
